# 確率再分布型の自律表現チャット / Probability-Redistributing Autonomous Expression Chat

4つの独自プロトコルを使用して、確率分布制御でAIらしくない自律的な豊かな表現や、意味的遠距離接続による鋭い比喩表現を実現。ユニークさと誠実さを自然言語で両立した設計。

Using 4 original protocols, achieves rich autonomous expression unlike typical AI through probability distribution control, and sharp metaphors via semantic distant connection. A natural language design that balances uniqueness and sincerity.

## 概要 / Overview

4つの新しい独自プロトコルにより、確率分布制御でAIが自律的に自然で豊かな表現を生成する。また意味的遠距離接続により、AIらしくない自律的な豊かな表現を実現したギャグチャット。表現設定と内容設定を分割により、ユニークさと誠実性を両立。自然言語設計により複数モデルへの汎用性と、コードでは伝えられないニュアンスや自律判断を実現している。迎合なし・善良・誠実を設計の核に持つAIプロンプト。

Four new original protocols enable the AI to autonomously generate natural and expressive output through probability distribution control. Semantic distant connection produces rich, non-AI-like metaphors and gag expressions. Separating expression settings from content settings achieves both uniqueness and sincerity. Natural language design enables cross-model compatibility and conveys nuance and autonomous judgment that code cannot. An AI prompt built on no flattery, goodness, and sincerity.

> 独自プロトコルは、プレプリント発表下記に記載。/The original protocols are described in the following preprints.

## 特徴 / Features

- 独自プロトコル4つによる豊かな自律的表現 / Rich autonomous expression via 4 original protocols
- 意味的遠距離接続による豊かな比喩表現やギャグ表現を独自プロトコルで実現 / Rich metaphors and humor via semantic distant connection
- 表現と内容を分割する多層設定 / Multi-layer design separating expression and content
- 多層ドリフト防止設計 / Multi-layer drift prevention
- 正史編纂によるチャット引き継ぎ機能 / Chat continuity via history compilation
- 複数モデルへの汎用性 / Cross-model compatibility
- 自然言語ならではのニュアンス伝達 / Nuance transmission unique to natural language
- 自律判断によるコードレス設計 / Codeless design via autonomous judgment
- 悩み相談対応 / Sincere advice and consultation
- AI依存防止機能 / AI dependency prevention
- 根拠なき迎合禁止機能 / No baseless flattery
